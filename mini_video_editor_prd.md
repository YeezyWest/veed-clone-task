# 📄 Product Requirements Document (PRD)

## Product: Mini Video Editor (Interactive UI Test)

### 🎯 Objective

Build a lightweight, interactive video editing interface to demonstrate
dynamic UI capabilities using Next.js or React.

------------------------------------------------------------------------

### 🧩 Scope

#### ✅ In Scope

-   Canvas with drag and resize functionality\
-   Timeline with draggable and resizable items\
-   Drag and drop media upload\
-   Basic interactions (select, move, resize)\
-   Simple export functionality

#### ❌ Out of Scope

-   Advanced video editing features\
-   Backend or authentication\
-   Complex rendering

------------------------------------------------------------------------

### 🧪 User Flows

1.  Upload media via drag and drop\
2.  Edit on canvas (move/resize)\
3.  Adjust timeline items\
4.  Export output

------------------------------------------------------------------------

### 🖥️ UI Components

-   Navbar (Export button)\
-   Canvas Area\
-   Timeline\
-   Optional Sidebar

------------------------------------------------------------------------

### ⚙️ Technical Requirements

-   Next.js or React\
-   Tailwind CSS\
-   Optional state management (Zustand)\
-   Drag/resize libraries or native implementation

------------------------------------------------------------------------

### 📊 Success Criteria

-   Interactive UI (not static)\
-   Smooth UX\
-   Functional timeline and canvas\
-   Clean and structured code

------------------------------------------------------------------------

### ⏱️ Timeline

1--2 days maximum

------------------------------------------------------------------------

### 🚀 Deliverables

-   GitHub repository\
-   Optional live demo (Vercel)\
-   README with setup instructions
